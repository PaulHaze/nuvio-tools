## OVERALL: Opus is the layout I prefer but with caveats.

Responsiveness is an issue. The whole screens shrinks with size. This is not ideal There needs to be a break point on for screens 1024 and below where the layout can follow Astra's lead:

- The left panel controls will need to become one column with the image.
- Put the picture sizes/ratio's at the top above the image.
- Image in the middle as it currently is
- Underneath that that the fit/cover buttons , then the range slider (along one row)
- The Folder set and naming box can become one feature. The name option at the top in a flex row on the left with the 'save' button at the other end on the right. The images already selected to be underneath it.

I said at first that this would be desktop early, but I am beginning to rethink that. It would be nice to be able to be mobile friendly too. Expanding on this single column approach, can we implement the changes above and try and another mock up that TRIES to be mobile friendly and see if it works? The prioirity is getting looking right and with good UX for desktop/tablet first though.
