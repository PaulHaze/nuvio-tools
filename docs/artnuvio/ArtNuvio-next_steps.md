Ok so we are going to go onto ArtNuvio next as I have a need for it and want to get a working MVP up. When I initially planned this it was going to be a separate app and as such there was a handoff doc made for it which can be found here: docs/artnuvio/ArtNuvio-HANDOFF.md

I think that oulines the main goal of it but I will repeat some things here.

- The goal is to provide a URL of any image already on the internet or generated by an LLM.

- We can then choose in what formats we want that image to be displayed (landscape, poster, hero)

- The image will be superimposed over an area that matches those nuvio dimensions (examples of the sizes are found in docs/images/artnuvio_examples)

- There will be a scale slider to enable to the user to grow or shrink the image. If the image is larger than nuvio art canvas then the user can move the image around by clicking within the canvas and moving the mouse.

- If the picture is in a different aspect ratio to what the user wants (landscape image being put into a poster, and vice versa) there will be radio button for fit / cover. Fit fits the whole image in , cover covers the whole frame with the image. The image can still be rezised whatever the user chooses. Resizing will remove the radio button being set. Pressing either of these radio button options after resizing will remove the size changes and place the image back into fit/cover mode.

- When the user is happy then the image will be uploaded to R2 storage, and a URL presented for the user to link to in his nuvio collections.

- If the image is a hero and is large enough to be the same size as docs/images/artnuvio_examples/hero_example.jpg then that is the size that is saved. If it is smaller then one of the smaller sizes are used. Landscape and posters will all be the size of the examples. Images MAY have to be increased (or decreased) to match the pixel size of the final image.

- Certain spam safety measure should be imposed to prevent bots or users abusing the service.

- This is all the MVP needs to do for now. No text, or gradients or color overlays or anything like that. That can come later. Lets just get a working version with the above specs for now.

Consider this the artnuvio mvp epic. Lets make some sprint tasks for this.
