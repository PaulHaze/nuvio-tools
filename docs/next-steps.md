# Next steps

Rough notes for upcoming work. Not a sprint doc: nothing here is decided yet.

## Next sprint: Listio look and UI tidy-up

Tidy up how Listio looks first, then work on the UI itself. Mainly:

- **List cards:** what a card shows and how it looks. Should it be detailed (poster, counts,
  sources, last updated) or minimal (name and a few key facts)? Possibly offer both.
- **Card layout:** how the lists are laid out on the page, as full-width rows, a card grid, or a
  choice between them.
- **Sort order:** how sorting works and where its controls sit. This covers the default order,
  the sort options, and whether the choice is remembered.
- **Things of that nature:** other rough edges on the Listio pages that turn up while doing the
  above.
